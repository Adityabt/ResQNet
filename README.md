# ResQNet

ResQNet is an emergency coordination web application prototype for organizing help requests, volunteer responses, incident updates, and supplies.

## What it does

- **Request help:** Submit an incident with its location, urgency, description, and requested resources.
- **Volunteer response:** Review the request queue and take responsibility for a request.
- **Coordinator workspace:** Track requests, coordinate volunteers, manage supplies, and publish updates.
- **Shared status:** Keep the people involved informed as requests change.

## Technology

React and TypeScript power the web interface. The backend uses Python and FastAPI, with SQLite for application data and REST and WebSocket interfaces for communication.

## Project status

ResQNet is an academic prototype. It has not been validated as an emergency dispatch service and does not replace official emergency services. In an immediate emergency, contact your local emergency number.
